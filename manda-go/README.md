## Vision en une phrase

**Manda Go** est la première application d'apprentissage du mandarin qui combine IA conversationnelle temps réel, reconnaissance vocale des tons et gamification de niveau AAA — au prix le plus bas du marché.

## Stack Technologique

```
Mobile:     Flutter 3.x (iOS + Android + Tablette)
Backend:    NestJS + Node.js 20 LTS
Base de données: PostgreSQL 16 + Redis 7
Cloud:      AWS (EKS, RDS, S3, CloudFront, SQS)
IA:         OpenAI GPT-4o + Whisper + TTS
Paiements:  Stripe Billing
Notifs:     Firebase FCM
CI/CD:      GitHub Actions → AWS ECR → EKS
```
