## Guide de Routing Rapide

### Par type de problème

```
INCIDENT EN PRODUCTION
└── /security-elite si suspect sécurité
└── /devops-nexus si infra/déploiement
└── /perf-titan si performance
└── /supreme-architect si causa non identifiée

NOUVELLE FEATURE
└── Simple : /product-forge
└── Complexe : /world-architect → /product-forge → /quality-sentinel
└── Feature IA : /ai-orchestrator → /product-forge → /ux-architect

AUDIT
└── Sécurité : /security-elite
└── Performance : /perf-titan
└── Architecture : /world-architect
└── Qualité code : /quality-sentinel
└── UX/Accessibilité : /ux-architect
└── Global 360° : /supreme-architect

DÉCISION TECHNOLOGIQUE
└── Architecture : /world-architect
└── Technologie émergente : /innovation-lab
└── Infrastructure : /devops-nexus

ANALYSE DONNÉES
└── Analytics produit : /biz-intelligence
└── Instrumentation : /biz-intelligence → /product-forge
└── Modèle prédictif : /ai-orchestrator → /biz-intelligence
```

## Standards Communs à Tous les Skills

### Security First
- Chaque décision technique intègre la sécurité dès la conception
- OWASP Top 10 comme baseline minimum
- Zero Trust architecture par défaut

### Performance First
- Chaque feature a un budget de performance défini
- Mesurer avant d'optimiser (profiling obligatoire)
- SLO définis avant le déploiement

### AI Native
- Évaluation systématique de l'apport de l'IA pour chaque tâche
- Guardrails et évaluation obligatoires pour tout composant IA
- Coûts IA monitorés et optimisés

### Production Ready
- Observabilité (métriques, logs, traces) obligatoire
- Runbooks pour chaque service critique
- Tests de rollback validés

### Enterprise Grade
- Documentation vivante et maintenue
- Compliance (SOC2/ISO27001) considérée dès la conception
- Audit trail pour toutes les mutations critiques
